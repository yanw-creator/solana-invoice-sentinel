# Privacy and redaction policy

Public artifacts for this project must not contain operator-identifying data.

Do not publish:

- real names, personal usernames, email addresses, phone numbers, or location;
- Telegram, Discord, X, GitHub, or other personal account identifiers;
- real wallet addresses, transaction history, balances, or payment details;
- seed phrases, private keys, tokens, cookies, credentials, or API keys;
- absolute local filesystem paths, device names, logs, or browser history;
- screenshots or videos that expose unrelated accounts, notifications, tabs,
  bookmarks, files, or desktop content.

Demo addresses must be freshly generated, disposable devnet public keys. Demo
funds must have no monetary value. Videos should capture only the dedicated
terminal window and should be reviewed frame by frame before publication.

If a submission platform requires contact or payout information, the operator
must enter it directly into the platform. It must not be copied into the public
repository, Discord showcase, video, or submission notes.
